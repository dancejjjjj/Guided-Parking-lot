# Smart Parking lot (concept demo)

Parking lot with Guiding RGB strip based on the **ESP32-S3** and **WS2812B**.

The code is ported from my another version using **Arduino Uno**.

## Description 
Tired of finding empty parking slot?

This project is a demo of how **Guiding System** works to save you a lot of time.
- When there are available slots, **Green** light will guide you to the nearest one.
- When there are no slot available, **Red** light will appear to tell you there is none left, saving your time moving around finding nothing.
